# MineVM Changelog

## Unreleased

- Added a FreeDOS system disc, `freedosIsoPath` runtime configuration, and a BIOS/IDE QEMU profile for FreeDOS installation and boot testing.
- Added a Windows 95 system disc, `windows95IsoPath` runtime configuration, and a capped low-memory BIOS/IDE QEMU profile for Windows 95 testing.

## 1.0.0

- Renamed the project, mod id, resource namespace, and release artifact to MineVM.
- Added stable in-world virtual computer hardware for Forge 1.20.1.
- Added BIOS-driven boot flows for installed disks and inserted system discs.
- Added local QEMU VM lifecycle management, display streaming through VNC frame updates, keyboard input, mouse input, cursor rendering, and power/disc controls.
- Added Ubuntu Server, Ubuntu Desktop, Windows XP, Windows 10, and Windows 11 disc items with per-disc ISO configuration.
- Stabilized immersive control behavior, VM reconnect behavior, framebuffer refresh, laptop/monitor interaction, and display rendering.
- Bound VM identity to the computer item NBT instead of the block coordinates, so replacing a fresh machine at the same position no longer inherits an old VM.
